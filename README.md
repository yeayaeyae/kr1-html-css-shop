# КР №1 — HTML и CSS: разработка многостраничного сайта
**ФИО:** Кигози Елисей Маликовчи
## Тема работы

Разработка многостраничного сайта интернет-магазина с использованием HTML и CSS.

## Цель работы

Создать многостраничный сайт с общей навигацией, каталогом товаров, страницей товара, формой оформления заявки и контактной информацией.

## О проекте

В рамках контрольной работы разработан учебный сайт интернет-магазина электроники **TechStore**.

Сайт состоит из нескольких связанных HTML-страниц и использует общую таблицу стилей CSS.
